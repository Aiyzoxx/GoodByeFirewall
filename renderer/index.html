Autorisation Administrateur

Pour activer le contournement DPI et charger le pilote réseau sécurisé WinDivert, GoodByeFirewall doit être exécuté avec les privilèges Administrateur.

Cette autorisation n'est demandée qu'une seule fois. Les prochains lancements se feront directement sans fenêtre UAC.
